## 📌 About

Cloud Secure Storage is a secure web application developed using **Python**, **Flask**, and **MySQL**. It protects sensitive files using encryption techniques before storing them in the cloud, helping ensure confidentiality and secure access.

This project is based on my **MCA (Cyber Security)** academic project and is being rebuilt with improved code quality, security, and documentation.
